## 📌 About PUPIL

**PUPIL** is an open-source EdTech platform built to make Computer Science learning more structured, accessible, and practical for college students.

Instead of forcing learners to search through disconnected tutorials, PUPIL organizes learning into focused technology tracks with:

* Structured curriculum
* Topic-wise learning modules
* Curated external resources
* Practice guidance
* Quizzes and assessments
* Project-based learning
* GitHub-oriented proof of work
* Open-source contribution opportunities

The platform currently contains **six major learning tracks**:

1. 🌐 Web Development
2. 🤖 AI / Machine Learning
3. ⚙️ DevOps
4. ☁️ Cloud Computing
5. 🧠 Data Structures & Algorithms
6. 🏗️ System Design

---

# 🎯 Vision

PUPIL follows a simple philosophy:

> **Learn → Practice → Assess → Build → Showcase**

The goal is not only to consume tutorials, but to help students convert learning into practical skills and portfolio-ready work.

# 🚀 Running the Project Locally

Since PUPIL is currently a static web application, it does not require a backend server.

### 1. Clone the repository

```bash
git clone https://github.com/PRITHVIBO/PUPIL.git
```

### 2. Enter the directory

```bash
cd PUPIL
```

### 3. Open the project

You can directly open:

```text
index.html
```

in your browser.

### Recommended: Run a local server

Using Python:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
