Recorded college lecture files go in this folder.

Each course page has a <video> player that looks for one file:

  webdev-lecture.mp4        -> webdev.html
  aiml-lecture.mp4          -> aiml.html
  devops-lecture.mp4        -> devops.html
  cloud-lecture.mp4         -> cloud.html
  dsa-lecture.mp4           -> dsa.html
  systemdesign-lecture.mp4  -> systemdesign.html

Drop an .mp4 with the matching name here and the player on that page starts working.
Until then the player shows the course poster image, and the "Watch Videos"
thumbnail above it opens the free YouTube playlist for that track.
