What is HTML?

HTML stands for HyperText Markup Language. It provides the structure of a webpage.

Important Tags

  • Headings
  • Paragraphs
  • Links
  • Images
  • Forms
  • Tables

Example

<h1>My Website</h1>

<p>Welcome to my website!</p>

<button>Click Me</button>
02

CSS

Design beautiful webpages

What is CSS?

CSS controls the appearance and layout of HTML elements.

Important Concepts

  • Selectors
  • Colors
  • Box Model
  • Flexbox
  • Grid
  • Responsive Design

Example

body {
    background: #f4f4f4;
}

h1 {
    color: blue;
}

button {
    padding: 10px;
}

JavaScript adds logic and interaction to webpages.

  • Functions
  • Arrays
  • Objects
  • DOM
  • Events
