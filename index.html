An Open Curriculum For Computer Science

Pupil is an open source learning platform for college computer science. We run six tracks — Web Development, AI/ML, DevOps, Cloud Computing, DSA and System Design — and the whole curriculum is open: readable, forkable and improvable by anyone.

We do not write yet another closed course. We curate the best openly published material from W3Schools, GeeksforGeeks, Stack Overflow, takeUforward and others, arrange it into a semester plan, and teach it in the lab.

Why An Open Source Program?

  • A student in any town can follow the same syllabus as a student in a metro city
  • The material stays updated, because the community updates it
  • You learn to read official documentation — the real skill in this industry
  • Nothing expires. Your notes and links keep working after you graduate
  • You can contribute back: fix a note, add a solution, open a pull request

How The Semester Runs

  1. Pick a track and read its syllabus table
  2. Follow the linked open tutorial for the current module
  3. Attend the lab session and build that module's project
  4. Solve the practice problems on LeetCode or the GfG practice portal
  5. Attempt the quiz and check where you stand
  6. Push your work to GitHub — that repository is your real certificate
